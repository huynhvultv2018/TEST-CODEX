==================================================
2. ROOT CAUSE TO VERIFY
==================================================

Kiểm chứng giả thuyết:

```text id="p121root"
LEGACY PACKAGE
HAS SUBJECT-RELATED METADATA

BUT

subject_engine IS MISSING
OR
subject_engine RESOLVES TO legacy/default
```

Loader hiện đang đồng nhất:

```text id="p121badmodel"
SUBJECT == PROFILE ENGINE
```

dẫn đến:

```text id="p121badresult"
Tin học package
+
legacy/default engine
=
SUBJECT MISMATCH
```

Phải kiểm chứng bằng source/runtime.

Không tự kết luận nếu evidence khác.
