# Phase 12 — Loader discovery contract

1. Subject routing dùng engine()/WebLiveProfiles resolver sẵn có: geometry/algebra/informatics/legacy; không có subject_engine → legacy, default → legacy, trim/case normalization giữ nguyên. Engine lạ/không hợp lệ vẫn bị validation block. Không profile inference từ title/subject/content.
2. Grade chỉ lấy lesson.grade; week và period chỉ lấy lesson.week/lesson.period. Catalog title được dùng để hiển thị nếu native lesson không có tên; catalog metadata không được thay thế actual lesson fields. class được hiển thị riêng nếu thiếu grade, không biến 8A thành grade8. Không filename fallback.
3. Chấp nhận scalar number/string cho discovery. Trim, maximum128characters, no data URI/nonfinite. Numeric decimal string được chuẩn hóa số (8 và "8" cùng lựa chọn); số sort trước, text metadata thật sort sau, missing cuối. Unusable field vào incomplete bucket; validation package gốc giữ nguyên. Không viết normalized values vào package.
4. Lựa chọn Grade từ actual subject rows; Week từ rows hợp Grade; Period từ rows hợp Grade+Week. All là wildcard; missing option xuất hiện chỉ khi có field thiếu. Missing field chưa thể xác nhận một known filter nên vẫn xuất hiện trong nhóm riêng nếu các field có sẵn khớp. Known mismatch bị ẩn ở filter đó nhưng truy cập lại được bằng All/giá trị thực. Chọn missing trực tiếp chỉ thu hẹp bài thật sự thiếu field. Không bài thiếu metadata bị loại khỏi thư viện.
5. Subject đổi reset Grade/Week/Period; Grade đổi reset Week/Period; Week đổi reset Period. Filter change clear pending/stale async revision; bài đang dạy/TV/disclosure/Focus/storage giữ nguyên đến load thành công. Không gọi start từ filter change.
6. Sort deterministic: grade/week/period numeric, title vi collator numeric, canonical ID tie-break. UI deduplicates catalog IDs only, không delete storage. Cùng title/profile/grade/week/period hiển thị ID để phân biệt. Cache unreadable/engine invalid vẫn ghi rõ, không nạp bypass.
7. Library và Recent gọi cùng openSaved/stage/validate/assets/profile routing/explicit commit. Recent/reference ngoài strict discovery scope reset G/W/P only, không tự đổi selected subject hay rewrite lesson. Missing reference clear pending/error và giữ current. Mismatch phải bị block, không auto-relabeled.
8. Commit, rollback, essential storage quota guard và optional quick-access writes giữ byte-exact. Native start/reset/sync cùng Core/Profile không thay đổi. Recent limit5; rememberSubject chỉ cập nhật sau successful commit. Không tự nạp từ quick access. Native accepted-session restore trên reload vẫn giữ nguyên, không lọc theo rememberedSubject.
9. RAM filter state3scalar values; transient descriptors bounded scalar metadata + IDs, no payload/assets retained. No new persistent index, no IndexedDB, cache migration, quota expansion or automatic deletion. Inherited explicit user-confirmed XÓA action giữ nguyên, không dùng trong task để giải quyết capacity.
10. Runtime candidate không chứa660lesson test library mới. Synthetic fixture/evidence/helpers là sidecars; không SGK/PPCT/real-file acceptance claim. One existing modal only. ≤5 meaningful interactions là target common scenario, không universal click guarantee. Windows/physicalTV/classroom UNRUN.
